# 三国覇王戦記 編成シミュレーター 使い方ガイド

## 1. システムの全体構成

```
┌─ メインシミュレータ (index.html) ──────────────┐
│  ・武将所持登録                                  │
│  ・編成構築（4プレイヤー × 8軍団）              │
│  ・スキル属性マトリクス・上限プール集計         │
│  ・ユーザー単位のJSONインポート/エクスポート    │
└──────────────────────────────────────────────────┘

┌─ 友人配布用ツール (register.html) ──────────────┐
│  ・スマホ最適化、所持入力に特化                  │
│  ・JSONエクスポート → 依頼者に送信              │
└──────────────────────────────────────────────────┘
```

## 2. 個人モード（あなた専用）の使い方

### 武将所持を登録する

1. 画面右側の **「武将一覧」** から、所持している武将の **所持チェック** を入れる
2. 各武将の育成段階を入力:
   - **3突 / 4突**: どちらか一方にチェック（突破段階）
   - **4装**: 装備完成済みならチェック（装備武将のみ）
   - **印**: 将印枚数（0〜10／将印武将のみ）
3. 一括設定: 表示中の武将に対し「所持/3突/4突/4装」を一括で適用

### 編成を組む

1. 画面中央の **編成エリア** に8軍団分の枠が並ぶ
2. プレイヤータブで対象プレイヤーを切り替え
3. 軍団ごとに **兵種** を選択（騎兵/歩兵/弓兵/戦車）
4. 各軍団の枠（部隊1〜5 × 統率/武力/知性 ＋ 角陣）に武将を割り当て
5. 集結時の共通優先属性（第一〜第五）を上部で指定
6. **「クイック選別」**（単軍団）／**「全軍団編成」**（全体最適）ボタンで自動編成も可能

### 集計結果を確認する

編成下部に以下が表示:

- **属性マトリクス**: 攻撃/防御/連撃/抵抗/貫通/シールド/貫通抵抗の符号付き合計を、スコープ別（集結/軍団/角陣/自部隊）に集計。セルクリックで詳細展開
- **上限プール状況**: cap ルール別の充足率・余裕量・候補武将提示
- **cap_rule 別集計**: 詳細な合計値
- **スキル詳細**: 武将別の解像度の高いブレイクダウン

## 3. 友人配布用ツールの使い方

### 友人への案内

以下のテンプレを使って案内してください:

```
お疲れさまです。三国覇王戦記の武将所持状況を集計したく、ご協力ください。

下記URLをスマホ/PCで開いて入力をお願いします。
👉 https://yuichi4107-lab.github.io/sangoku-sim/register.html

【手順】
1. 名前を入力
2. 所持している武将にチェック + 段階入力（3突/4突/4装/印）
3. 「📤 送信」ボタンを押して送信
```

または index.html 上部の **「📱 QR」ボタン** で QR コードを表示して読み取ってもらえます。

### 友人側の操作

- 名前入力 → 武将カードで所持＋段階チェック → 「📤 送信」
- 入力途中の状態はブラウザに自動保存
- 何度に分けて入力してもOK

### あなた側で取り込み

1. 受信箱（後述）に友人データが届く
2. index.html の **「📥 受信箱を取得」** をクリック
3. モーダルで取り込みたいユーザーを選択 → 取込で自分の編成シミュレーターに追加/上書き

## 4. ユーザー単位のインポート/エクスポート

### エクスポート（既存登録済みプレイヤーを出力）

1. index.html の **「ユーザーをエクスポート」** をクリック
2. モーダルで対象プレイヤーを選択（全選択/全解除ボタンあり、初期は全選択）
3. 「エクスポート」→ 各プレイヤーごとに JSON ファイルがダウンロード

### インポート

1. JSON ファイルを準備
2. index.html の **「ユーザーをインポート」** をクリック → ファイルを複数選択可
3. 同名プレイヤーがいた場合は上書き確認ダイアログ

## 5. データ管理

### ローカル保存（localStorage）

- メインシミュ: キー `sangoku_sim_v06`
- 登録ツール: キー `sangoku_register_v1`

### バックアップ・移行

- **個人データのバックアップ**: 「ユーザーをエクスポート」で定期的に JSON 保存推奨
- **新端末への移行**: 旧端末で「ユーザーをエクスポート」→ 新端末で「ユーザーをインポート」

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「データロードエラー」表示 | ハードリロード（Ctrl+Shift+R）、それでも駄目ならブラウザキャッシュ削除 |
| 友人JSON取り込みでエラー | スキーマが `sangoku_user_v1` か確認、JSONの破損確認 |
| 編成が壊れた | 過去のエクスポートJSONからインポートで復旧 |
| 武将データが古い | 1〜2分待ってからリロード（更新時に自動再ビルド） |
