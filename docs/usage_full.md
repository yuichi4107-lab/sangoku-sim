# 三国覇王戦記 編成シミュレーター 使い方ガイド（管理者版・同期モード含む）

最終更新: 2026-05-27

## 1. システムの全体構成

```
┌─ メインシミュレータ (index.html) ──────────────┐
│  ・武将所持・育成段階の登録                      │
│  ・編成構築(複数プレイヤー × 8軍団)             │
│  ・スキル属性マトリクス・上限プール集計         │
│  ・ユーザー単位の JSON インポート/エクスポート  │
│  ・友人データの受信箱取り込み                    │
│  ・グループ同期(解錠後利用可)                    │
└──────────────────────────────────────────────────┘

┌─ 友人配布用ツール (register.html) ──────────────┐
│  ・スマホ最適化、所持入力に特化                  │
│  ・「📤 送信」で受信箱へ送信(画像添付対応)      │
└──────────────────────────────────────────────────┘

┌─ 登録状況ダッシュボード (status.html) ───────────┐
│  ・全武将のスキル登録状況を一覧表示              │
│  ・タイプ別フィルタ・要対応のみ・武将名検索      │
│  ・武将名タップで登録スキル詳細を展開            │
└──────────────────────────────────────────────────┘
```

## 2. メインシミュレータの使い方

### 武将バッジとタイプ
各武将には**タイプバッジ**が表示されます:
- **将印**(赤): 将印武将
- **装備**(青): 装備武将
- **無印**(灰): それ以外

絞り込みは「兵種」と「タイプ」の2つから可能。

### 武将所持を登録する
1. 武将一覧の **所持** チェックを入れる。
2. **育成段階**は武将タイプによって表示が変わります:

| タイプ | 表示される育成項目 |
|---|---|
| **無印武将** | 3突 / 4突(突破段階。どちらかにチェック) |
| **装備武将** | 3突 / 4突 ＋ **3装 / 4装**(装備段階。どちらかにチェック) |
| **将印武将** | 3突 / 4突 ＋ **印**(将印 0〜10) |

※ 4突の後は装備または将印になる仕様。4装と将印は排他(同一武将で両立しない)。

### 一括設定
表示中の武将に対して以下を一括適用できます:
- 所持
- 3突 / 4突
- **3装 / 4装**(装備武将のみ対象)

### 編成を組む
1. プレイヤータブで対象プレイヤーを切り替え。
2. 軍団ごとに **兵種** を選択(騎兵 / 歩兵 / 弓兵 / 戦車)。
3. 各軍団の枠＝ **部隊1〜5 ×(統率 / 武力 / 知性)＋ 角陣 ×(統率 / 武力 / 知性)** に武将を割り当て。
4. 集結時の **優先属性を第一〜第五** まで上部で指定(編成全体で共有)。
5. 自動編成ボタン:
   - **クイック選別**(単軍団): その軍団だけを自動編成。
   - **全軍団編成**(複数軍団・**全体最適**): チェック中の軍団を、全スロット横断でグローバル貪欲＋入れ替え改善により最適化。
6. 自動編成後、軍団内の枠は **担当条件スキル ＞ 角陣スキル ＞ 能力値順** で並べ替えられます(統率部隊1→5、武力部隊1→5、知性部隊1→5、角陣の順)。

### 集計結果を確認する
編成下部に以下が表示されます:
- **属性マトリクス**: 攻撃/防御/連撃/抵抗/貫通/シールド/貫通抵抗 をスコープ別(集結/軍団/角陣/自部隊)に符号付き集計。セルクリックで詳細展開。
- **上限プール状況**: cap ルール別の充足率・余裕量・追加候補武将。
- **武府属性ハイライト**: プレイヤーが投資した属性(連撃/抵抗/貫通 等)を兵種マトリクス上で色付け表示。
- **スキル詳細**: 武将別の解像度の高いブレイクダウン。

## 3. 友人配布用ツール(register.html)の使い方

### 友人への案内

```
お疲れさまです。三国覇王戦記の武将所持状況を集計したく、ご協力ください。

下記URLをスマホ/PCで開いて入力をお願いします。
👉 https://yuichi4107-lab.github.io/sangoku-sim/register.html

【手順】
1. 名前を入力
2. 所持している武将にチェック ＋ 育成段階(3突/4突、装備武将なら3装/4装、将印武将なら印)を入力
3. 「📤 送信」ボタンを押す(任意で兵士属性のスクショを添付)
4. 完了。入力途中で閉じても自動保存されます
```

QRコードからもアクセス可。

### 友人側の操作
- 名前入力 → 武将カードで所持＋育成段階チェック → 「📤 送信」。
- 入力途中の状態はブラウザに自動保存され、何度に分けて入力してもOK。
- 兵士属性(武府)のスクショを送信時に添付すると、こちら側でOCR取り込み可能。

### あなた側で取り込み
1. メインシミュレータ右上の **「📥 受信箱」** をクリック。
2. モーダルに送信者の一覧(名前・所持数・更新日時・画像・兵士属性の有無)が表示。
3. 取り込みたい友人にチェック → 「取込」でユーザーとして追加/上書き。
4. 兵士属性は **「📋 ステ編集」** で手動編集、または **「🤖 全員OCR」** で画像から一括認識可能。

## 4. ユーザー単位のインポート/エクスポート

### エクスポート
1. **「ユーザーをエクスポート」** をクリック。
2. 対象プレイヤーを選択 → エクスポート → JSON ファイルダウンロード。

### インポート
1. JSON ファイルを準備し **「ユーザーをインポート」** をクリック → 複数選択可。
2. 同名プレイヤーがいた場合は上書き確認ダイアログ。

## 5. グループ同期機能(クラウド共有)

### 概要
複数デバイス(PC・スマホ)で **同じ状態を共有** したい場合、または **複数人で同時編集** したい場合に使用。
Google Apps Script ＋ Google Sheets をバックエンドとして利用。

### 解錠方法(初回のみ)
1. 画面下端の **「⚙️」ボタン** をクリック。
2. アクセスコード入力 → **`sangoku2026`** を入力。
3. 解錠完了。以降はそのデバイス／ブラウザで常時表示。

### 使い方
解錠後、フッター上に表示される **「🔓 グループ同期」パネル**:

| ボタン | 動作 |
|---|---|
| **⬇️ クラウドから取得** | クラウド上の最新データでこの端末を上書き |
| **⬆️ クラウドへ保存** | 現在のローカル状態をクラウドへ送信(他端末・他メンバーに反映) |
| **🧪/🔗 モード切替** | 試作モード／同期モードの切り替え(試作時は保存ボタンが警告色) |
| **📥 受信箱** | 友人 register.html からの送信データを取得・取込 |

### 何が同期されるか
- ユーザー一覧、各ユーザーの **所持・育成段階**、兵士属性(武府)、編成(軍団・部隊配置・兵種)、優先属性、集計モード。
- **武将マスタ(generals.yaml)は同期対象外**。これは GitHub Pages 経由で全員共通配布。

### 推奨フロー
1. 管理者がローカルでデータを整える → **「⬆️ クラウドへ保存」** で初期化。
2. 他メンバーが解錠 → **「⬇️ クラウドから取得」** で初期データ取得。
3. 編集後は **「⬆️ クラウドへ保存」** を押す(自動アップロードはしない)。

### 注意点
- **方式**: 後勝ち(last-write-wins)。同時刻に複数人が保存すると後の方で上書きされる。
- **権限**: 全員が全員のデータを編集可能(運用ルールで補完)。
- **解錠状態の管理**: アクセスコードを知らない人には機能自体が見えない。

## 6. データ管理

### ローカル保存(localStorage)
- メインシミュ: `sangoku_sim_v06`
- 登録ツール: `sangoku_register_v1`
- グループ解錠状態: `sangoku_group_unlocked_v1`
- 同期モード/試作モード: `sangoku_group_mode_v1`

### バックアップ・移行
- 「ユーザーをエクスポート」で定期的に JSON 保存推奨。
- グループ機能利用時はクラウドが正、ローカルは作業端末用キャッシュ。

## 7. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「データロードエラー」表示 | ハードリロード(Ctrl+Shift+R)、それでも駄目ならブラウザキャッシュ削除 |
| 編成が壊れた | 過去のエクスポート JSON からインポートで復旧 |
| 武将データが古い | 1〜2分待ってからリロード(更新時に自動再ビルド) |
| グループ同期で「取得失敗」 | GAS Web App URL が変わった可能性。管理者に連絡 |
| 受信箱で「取得失敗」 | 通信状態を確認のうえ、再度「📥 受信箱」を押下 |

## 8. データ更新フロー(管理者向け)

新しい武将データ追加:
1. `generals.yaml` を編集(またはスクショ取込で自動更新)。
2. `python scripts/classify_skill_attributes.py` で属性再分類。
3. `python scripts/inline_data_to_html.py` で各 HTML に埋め込み。
4. git commit & push → GitHub Actions で自動再ビルド → GitHub Pages に反映。

GitHub Actions が走るのは以下のファイル変更時:
- `generals.yaml`
- `scripts/classify_skill_attributes.py`
- `scripts/inline_data_to_html.py`
- `.github/workflows/build.yml`
