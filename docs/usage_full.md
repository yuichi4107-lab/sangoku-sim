# 三国覇王戦記 編成シミュレーター 使い方ガイド（管理者版・同期モード含む）

最終更新: 2026-05-31

## 1. システムの全体構成

```
┌─ メインシミュレータ (index.html) ──────────────┐
│  ・編成構築(複数プレイヤー × 8軍団)             │
│  ・スキル属性マトリクス・上限プール集計         │
│  ・武将所持・育成段階の表示・編集               │
│  ・「🔄 登録ツールから取込」                    │
│  ・ユーザー単位の JSON インポート/エクスポート  │
│  ・グループ同期(解錠後利用可)・受信箱           │
└──────────────────────────────────────────────────┘

┌─ 所持登録ツール (register.html) ────────────────┐
│  ・スマホ最適化、所持入力に特化                  │
│  ・自分用の主入力／友人にも配布可能              │
│  ・「📤 送信」で受信箱へ送信(画像添付対応)      │
└──────────────────────────────────────────────────┘

┌─ 登録状況ダッシュボード (status.html) ───────────┐
│  ・全武将のスキル登録状況を一覧表示              │
│  ・タイプ別フィルタ・要対応のみ・武将名検索      │
│  ・武将名タップで登録スキル詳細を展開            │
└──────────────────────────────────────────────────┘
```

## 2. かんたん運用フロー(推奨)

普段はこの2ステップだけでOKです:

1. **register.html(所持登録ツール)** で自分の名前と所持・育成段階を入力。
2. **メイン** を開いて、ツールバー上部の **「🔄 登録ツールから取込」** をクリック。

→ あとはメインで兵種・優先属性を指定して「クイック選別」「全軍団編成」で自動編成、属性マトリクスや上限プールで結果を確認。

## 3. メインシミュレータの使い方

### 武将バッジとタイプ
各武将には**タイプバッジ**が表示されます:
- **将印**(赤): 将印武将
- **装備**(青): 装備武将
- **無印**(灰): それ以外

絞り込みは「兵種」と「タイプ」の2つから可能。

### 武将所持を登録する
1. 武将一覧の **所持** チェックを入れる。
2. **育成段階**は武将タイプによって表示が変わります:

| タイプ | 表示される育成項目 |
|---|---|
| **無印武将** | 3突 / 4突(突破段階。どちらかにチェック) |
| **装備武将** | 3突 / 4突 ＋ **3装 / 4装**(装備段階。どちらかにチェック) |
| **将印武将** | 3突 / 4突 ＋ **印**(将印 0〜10) |

※ 4突の後は装備または将印になる仕様。4装と将印は排他(同一武将で両立しない)。

### 一括設定
表示中の武将に対して以下を一括適用できます:
- 所持
- 3突 / 4突
- **3装 / 4装**(装備武将のみ対象)

### 編成を組む
1. プレイヤータブで対象プレイヤーを切り替え。
2. 軍団ごとに **兵種** を選択(騎兵 / 歩兵 / 弓兵 / 戦車)。
3. 各軍団の枠＝ **部隊1〜5 ×(統率 / 武力 / 知性)＋ 角陣 ×(統率 / 武力 / 知性)** に武将を割り当て。
4. 集結時の **優先属性を第一〜第五** まで上部で指定(編成全体で共有)。
5. 自動編成ボタン:
   - **クイック選別**(単軍団): その軍団だけを自動編成。
   - **全軍団編成**(複数軍団・**全体最適**): チェックを入れた軍団を、全軍団横断でまとめて最適化。

### 自動編成のしくみ(要点)
- **スキル優先スコアで選定**: 指定した優先属性(第一〜第五)にマッチするスキルの効き具合で武将を評価。上限(cap)に達した属性は加点されず、余裕のある属性を埋める武将が選ばれやすい。
- **段階的に枠を確定**: ① 全軍団の**主陣・統率枠**(率兵に直結)→ ② 主陣の武力・知性 → ③ 角陣の統率 → ④ 角陣の残り、の順に開放して選定。統率を全軍団で先に確保。
- **18人が決まると配置も確定**: 各枠タイプ(統率/武力/知性/角陣)に選ばれた武将はその枠に確定し、同じ枠タイプ内では**能力値の高い順**に部隊1→5へ並ぶ。
- **戦車武将のルール**: 1軍団あたり**最大3人**まで。配置は**角陣のみ**(部隊枠には入らない)。
- **強制選択武将**: 関平(騎兵) / 蒋欽(弓兵) / 李典(歩兵) / 張遼(万能) は、兵種指定済みの対象軍団がある場合に優先して配置される。
- **派遣不要だけの武将**は自動編成では配置されない(数値は所持で常時加算)。手動では選べる。
- **兵種・担当条件**: 「騎兵○○」「統帥担当時」等のスキルは、軍団兵種・配置枠が合うときだけ加点。
- 詳細は `docs/formation_rules.md` を参照。

### 集計結果を確認する
編成下部に以下が表示されます:
- **属性マトリクス**: 攻撃/防御/連撃/抵抗/貫通/シールド/貫通抵抗 をスコープ別(集結/軍団/角陣/自部隊)に符号付き集計。セルクリックで詳細展開。
- **上限プール状況**: cap ルール別の充足率・余裕量・追加候補武将。
- **武府属性ハイライト**: プレイヤーが投資した属性(連撃/抵抗/貫通 等)を兵種マトリクス上で色付け表示。
- **スキル詳細**: 武将別の解像度の高いブレイクダウン。

## 4. 所持登録ツール(register.html)の使い方

register.html は **スマホでの主入力ツール**として使えます。同じブラウザで開けば、メインの「🔄 登録ツールから取込」で取り込めます。

### 入力手順
1. 上部の **「👤 名前」** に自分の名前を入力。
2. 武将カードで **所持** をチェック → 育成段階(3突/4突、装備武将は3装/4装、将印武将は印 0〜10)を入力。
3. フィルタ(兵種・タイプ・🔍武将名検索・所持のみ)で絞り込み可能。
4. 入力内容はブラウザに自動保存されます。途中で閉じても続きから入力可。

### 所持を更新して再送信する(一から入力しない)
新しい武将を取った等で再送信したいとき、ゼロから入れ直す必要はありません。
- 同じ端末・ブラウザなら、前回の入力が**自動保存**されているのでそのまま続きから編集できます。
- 機種変更・別端末・キャッシュ消去後は、**名前を入力 → 「📥 前回の登録を呼び戻す」** を押すと、
  サーバーに残っている**前回送信した内容**が画面に復元されます。差分だけ直して「📤 送信」すればOK。
  - ※ 前回と**同じ名前**で照合します(全角/半角・空白も区別)。

### メインに反映する
- 同じブラウザでメインを開き、上部の **「🔄 登録ツールから取込」** をクリック。
- 同名ユーザーがいれば上書き確認、いなければ新規追加。
- 別端末・別ブラウザに移したい場合はメインの **「ユーザーをインポート / エクスポート」** で JSON 経由（または同期モード経由）。

### 友人に配布して所持を集めたい場合
以下のテンプレで案内できます:

```
お疲れさまです。三国覇王戦記の武将所持状況を集計したく、ご協力ください。

下記URLをスマホ/PCで開いて入力をお願いします。
👉 https://yuichi4107-lab.github.io/sangoku-sim/register.html

【手順】
1. 名前を入力
2. 所持している武将にチェック ＋ 育成段階(3突/4突、装備武将なら3装/4装、将印武将なら印)を入力
3. 「📤 送信」ボタンを押す(任意で兵士属性のスクショを添付)
4. 完了。入力途中で閉じても自動保存されます
```

QRコードからもアクセス可。

### 友人側から届いたデータの取り込み(管理者・同期モード)
- メインで同期モードを解錠した管理者は **「📥 受信箱」** から友人の送信データを取り込めます(詳細は §6)。

## 5. ユーザー単位のインポート/エクスポート(JSON)

### エクスポート
1. メインで **「ユーザーをエクスポート」** をクリック。
2. 対象プレイヤーを選択 → エクスポート → JSON ファイルがダウンロードされます。

### インポート
1. JSON ファイルを準備し **「ユーザーをインポート」** をクリック → 複数選択可。
2. 同名プレイヤーがいた場合は上書き確認ダイアログ。

## 6. グループ同期機能(クラウド共有・管理者向け)

### 概要
複数デバイス(PC・スマホ)で **同じ状態を共有** したい場合、または **複数人で同時編集** したい場合に使用。
Google Apps Script ＋ Google Sheets をバックエンドとして利用。

### 解錠方法(初回のみ)
1. 画面下端の **「⚙️」ボタン** をクリック。
2. アクセスコード入力 → **`sangoku2026`** を入力。
3. 解錠完了。以降はそのデバイス／ブラウザで常時表示。

### 使い方
解錠後、フッター上に表示される **「🔓 グループ同期」パネル**:

| ボタン | 動作 |
|---|---|
| **⬇️ クラウドから取得** | クラウド上の最新データでこの端末を上書き |
| **⬆️ クラウドへ保存** | 現在のローカル状態をクラウドへ送信(他端末・他メンバーに反映) |
| **🧪/🔗 モード切替** | 試作モード／同期モードの切り替え(試作時は保存ボタンが警告色) |
| **📥 受信箱** | 友人 register.html からの送信データを取得・取込(モーダルで送信者選択 → 取込) |

### 何が同期されるか
- ユーザー一覧、各ユーザーの **所持・育成段階**、兵士属性(武府)、編成(軍団・部隊配置・兵種)、優先属性、集計モード。
- **武将マスタ(generals.yaml)は同期対象外**。これは GitHub Pages 経由で全員共通配布。

### 受信箱の使い方
- 友人が register.html で **「📤 送信」** したデータが受信箱に蓄積されます。
- **「📥 受信箱」** クリック → モーダルに送信者一覧(名前・所持数・更新日時・画像・兵士属性) → チェックして「取込」でユーザー追加/上書き。
- 兵士属性は **「📋 ステ編集」** で手動編集、または **「🤖 全員OCR」** で画像から一括認識可能。

### 推奨フロー
1. 管理者がローカルでデータを整える → **「⬆️ クラウドへ保存」** で初期化。
2. 他メンバーが解錠 → **「⬇️ クラウドから取得」** で初期データ取得。
3. 編集後は **「⬆️ クラウドへ保存」** を押す(自動アップロードはしない)。

### 注意点
- **方式**: 後勝ち(last-write-wins)。同時刻に複数人が保存すると後の方で上書きされる。
- **権限**: 全員が全員のデータを編集可能(運用ルールで補完)。
- **解錠状態の管理**: アクセスコードを知らない人には機能自体が見えない。

### 要望の受付(半自動)
同期モード解錠者(アクセスコードを知るメンバー)だけが使える要望機能:
- **「💡 要望を送る」**: 名前・種別(バグ報告/武将データ修正/機能要望/その他)・本文を送信 → `requests` シートに保存。AIと相談して、原文・整理・実装前プラン・受け入れ条件付きの本文に整えてから送信できる。
- **「📋 要望一覧」**: 届いた要望を一覧表示（未対応→承認→対応済→却下の順、ヘッダに未対応/承認の件数）。各要望のステータス変更・削除。
  - ステータス: **未対応 / 承認(実装する) / 対応済 / 却下**。

**承認→実装の流れ(半自動)**
1. 要望を見て、実装したいものを **「承認(実装する)」** にする(やらないものは「却下」)。
2. このツール(Claude Code)との会話で **「承認した要望を実装して」** と依頼。
3. 承認済み要望をサーバーから取得 → 実装 → 内容を確認 → push(CIで公開) → 「対応済」に更新。
   - ※ 承認ボタンを押した瞬間に無人で実装・公開はされない(安全のため、実装は会話を起点に行う)。
   - ※ コードへの自動反映はしない。誤った/危険な要望は承認しなければ反映されない。

### ローカル保存(localStorage)
- メインシミュ: `sangoku_sim_v06`
- 登録ツール: `sangoku_register_v1`
- グループ解錠状態: `sangoku_group_unlocked_v1`
- 同期モード/試作モード: `sangoku_group_mode_v1`

### バックアップ・移行
- 「ユーザーをエクスポート」で定期的に JSON 保存推奨。
- グループ機能利用時はクラウドが正、ローカルは作業端末用キャッシュ。

## 8. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「データロードエラー」表示 | ハードリロード(Ctrl+Shift+R)、それでも駄目ならブラウザキャッシュ削除 |
| 「🔄 登録ツールから取込」で何も入らない | 同じブラウザで register.html を開いて入力したかを確認(別端末・別ブラウザは対象外) |
| 編成が壊れた | 過去のエクスポート JSON からインポートで復旧 |
| 武将データが古い | 1〜2分待ってからリロード(更新時に自動再ビルド) |
| グループ同期で「取得失敗」 | GAS Web App URL が変わった可能性。管理者に連絡 |
| 受信箱で「取得失敗」 | 通信状態を確認のうえ、再度「📥 受信箱」を押下 |

## 9. データ更新フロー(管理者向け)

新しい武将データ追加:
1. `generals.yaml` を編集(またはスクショ取込で自動更新)。
2. `python scripts/classify_skill_attributes.py` で属性再分類。
3. `python scripts/inline_data_to_html.py` で各 HTML に埋め込み。
4. git commit & push → GitHub Actions で自動再ビルド → GitHub Pages に反映。

GitHub Actions が走るのは以下のファイル変更時:
- `generals.yaml`
- `scripts/classify_skill_attributes.py`
- `scripts/inline_data_to_html.py`
- `.github/workflows/build.yml`
