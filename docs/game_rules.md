# 三国覇王戦記 ゲーム内ルール（シミュレータ仕様の参照元）

ゲーム内のルール説明ポップアップから書き起こした計算ルール集。  
シミュレータのロジックはここに記載のルールを反映する。

## スキルの下限（敵方デバフが下げきれない床）

ソース: ゲーム内「ルール説明」ポップアップ（IMG_0671 / IMG_0672, 2026-05-15 取得）

### [1] 集結主陣・貫通の下限
戦闘時、敵方の集結主陣内の全兵士の貫通を **基礎貫通の10%** 下限以下に下げさせても、最終ダメージは元のダメージの **下限10%** 以下にならない。

### [2] 属性別の下限（連撃・抵抗・貫通・貫通抵抗・シールド・軍紀 vs 攻撃・防御）
戦闘時、味方が敵方の属性値を減少させても以下を下回らない:

| 属性カテゴリ | 下限 |
|---|---|
| 連撃 / 抵抗 / 貫通 / 貫通抵抗 / シールド / 軍紀 | **20%** |
| 攻撃 / 防御 | **10%** |

例:
- 敵方の貫通を下限20%以下に下げられない。
- 敵方の攻撃力を×10%以下に下げられない。

### [3] 最終ダメージの下限
戦闘時/交戦時、敵方が与えるダメージを味方が低下させても、最終ダメージは元のダメージの **下限10%** を下回らない。

例:
- 敵方ダメージを20%低下しても、最終ダメージは元の10%以下にならない。

### [4] 交戦時の攻撃・防御下限
交戦時、敵方の攻撃・防御属性の属性値の **下限10%** を下回らない。

例:
- 敵方の攻撃力を初回交戦前×20%低下させても、初回交戦前の10%以下にならない。

## シミュレータでの扱い

`generals.yaml` の `meta.floor_rules` に構造化データとして保持。  
ダメージ計算で属性別デバフ累計を表示する場合、これらの下限を適用してクランプする。

```yaml
meta:
  floor_rules:
    attack: 10      # 攻撃 下限10%
    defense: 10     # 防御 下限10%
    rensa: 20       # 連撃 下限20%
    resist: 20      # 抵抗 下限20%
    pierce: 20      # 貫通 下限20%
    pierce_resist: 20  # 貫通抵抗 下限20%
    shield: 20      # シールド 下限20%
    discipline: 20  # 軍紀 下限20%
    final_damage: 10  # 最終ダメージ 下限10%
```
