# 自動編成（クイック選別）ルール

最終更新: 2026-06-04

## 1. 起動条件

- 各軍団の「クイック選別」ボタンで実行
- **軍団の兵種指定**が必須
- **優先属性を1つ以上**（第一〜第五）指定が必須

## 2. 候補武将（プール）

以下を**すべて満たす**武将が候補:

- 対象プレイヤーが**所持**している
- 同じプレイヤーの**他軍団で未使用**
- **配置して意味のある戦闘系スキルを持つ**（攻撃/防御/連撃/ダメージ/兵士…等のキーワード。**派遣不要スキルしか持たない武将は除外** → 第7節）
- **兵種が枠に合う**（兵種優先 → 下記）

### 兵種優先（武将の troop_type による候補限定）
軍団の兵種指定に応じて、配置できる武将の兵種を限定する:

軍団兵種の指定は **歩兵 / 騎兵 / 弓兵 の3種のみ**（戦車・万能は主陣兵種に選べない）。

| 枠 | 候補にできる武将の兵種 |
|---|---|
| **主陣**（部隊1〜5）| **軍団兵種 ＋ 万能**（例: 歩兵軍団なら歩兵・万能のみ）|
| **角陣** | **戦車優先**（最大3 → 第6-5節）。**戦車がいない/足りない枠は 軍団兵種 ＋ 万能 で埋める** |

- 角陣は戦車を最優先で配置し、戦車が3人未満なら残り枠を軍団兵種（＋万能）で充足する。
- slot_stat（統率/武力/知性の登録属性）は配置可否に影響しない（スキルの担当条件はスコアで考慮 → 第4節）。

### 強制選択武将

以下の武将は、自動編成で通常スコアより優先して選択する。

| 武将 | 兵種 | 強制選択される条件 |
|---|---|---|
| 関平 | 騎兵 | 騎兵の軍団が兵種指定されている |
| 蒋欽 | 弓兵 | 弓兵の軍団が兵種指定されている |
| 李典 | 歩兵 | 歩兵の軍団が兵種指定されている |
| 張遼 | 万能 | いずれかの軍団で兵種指定されている |

- 兵種未指定の軍団は従来どおり自動編成対象外のため、強制選択もしない。
- 強制選択武将も、対象プレイヤーが所持していること、同じプレイヤーの他軍団で未使用であることを前提にする。
- 張遼は `troop_type: 万能` のため、歩兵・騎兵・弓兵のどの指定軍団にも配置できる。

## 3. スコア計算（限界貢献）

各武将を各スロットに置いた時の貢献度を計算する。

### 除外されるスキル

| 除外されるスキル | 理由 |
|---|---|
| 派遣不要スキル | 配置不要で常時発動 → 配置貢献に数えない |
| 配置条件が不一致 | 「主将担当時」等で違うスロットなら発動しない |
| 兵種条件が不一致 | 「騎兵○○」等で軍団兵種と違えば発動しない |
| 優先属性に非マッチ | 第一〜第五のいずれにも該当しない |

### 加点される値

- 優先属性にマッチするスキルの実効値
- **上限（cap）適用後の値**（下記参照）
- 優先度の重み: 第一=16 / 第二=8 / 第三=4 / 第四=2 / 第五=1
- 各スキルは**最上位にマッチした優先度1つ**に加算

### 上限（cap）の扱い ― 「上限に満たない分だけ加点」

スキルには上限（cap）が設定されているものがある。スコアには **上限に達していない残り分（=実際に効果が増える分）だけ** を加点する。

#### 共有プールの場合

複数武将が同じ上限プールを食い合うスキル（例: 連撃ダウン共有プール上限50%）では、**今すでに編成に入っている合計値**を見て、上限までの増分のみを加点する。

```
例) 上限 80%、現在プール合計 60% のとき
  +30% のスキルを持つ武将を追加 → 80% までの「20%分」だけ加点
  （超過する 10% は無駄なので加点しない）

例) 既に上限 80% に到達済みのとき
  +30% のスキルを追加しても加点は 0
  （置いても効果が増えないため、その武将の優先度は下がる）
```

→ これにより「**上限に余裕がある属性を埋められる武将**」が高評価になり、すでに上限到達した属性に偏らないよう自動調整される。

#### 個別（非共有）の場合

その武将のスキル単独で上限を超える分はカットして加点する。

```
例) 上限 25% のスキルで実効値が 30% の場合 → 25% 分だけ加点
```

## 4. 配置条件の検出（自身がそのスロットを担当する条件）

| スロット | 検出する効果文の表現 |
|---|---|
| 統率 | 統帥を担当 / 統率を担当 / 主将になった / 主将を担当 / 主将担当 / 主将の時 |
| 武力 | 先鋒を担当 / 前衛を担当 / 先鋒担当 / 前衛担当 |
| 知性 | 軍師を担当 / 参謀を担当 / 知性を担当 |
| （条件なし）| どのスロットでも発動 |

※「陣の統帥が…」のような他者参照は条件にしない（自身担当のみ判定）。

## 5. 兵種条件の検出（特殊兵含む）

| 効果文の対象 | 判定兵種 |
|---|---|
| **味方[兵種]に対する…**（例: 味方歩兵に対する敵方騎兵の抑制係数）| **味方側の兵種**（その兵種が単一に特定できる場合のみ）|
| 騎兵○○ / 歩兵○○ / 弓兵○○ / 戦車○○（単一言及）| その兵種 |
| 連弩兵 | 弓兵（特殊兵）|
| 槍盾兵 / 盾槍兵 | 歩兵（特殊兵）|
| 猛獣 | 騎兵（特殊兵）|
| 全兵士 / 全軍 / 一兵種 / 複数の味方兵種に言及 | 兵種非依存（どの軍団でも有効）|

※「味方[兵種]」検出は最優先。例: 厳法「味方歩兵に対する敵方騎兵の抑制係数低下」→ 歩兵軍団でのみ加点。
　味方の兵種が複数に分かれるもの（例: 死闘＝味方騎兵の攻撃＋味方歩兵の防御）は兵種非依存（どちらの軍団でも一部有効）。

## 6. 配置順序とスコア0の扱い

### 6-0. スロット開放フェーズ（統率を先に確定）★両編成共通
スロットを一括では埋めず、以下の **4フェーズの順** に開放して選定する。
率兵に直結する**統率枠を全軍団で先に確定**してから残りを埋める意図。

1. **主陣の統率**（各軍団 部隊1〜5の統率＝5枠）
2. **主陣の武力・知性**（10枠）
3. **角陣の統率**（1枠）
4. **角陣の武力・知性**（2枠）

- フェーズ①②（主陣）には**戦車武将を入れない**（戦車は角陣のみ）。③④（角陣）で戦車を選定（上限3）。
- 各フェーズ内の選定基準は従来の**スキル優先スコア**（§3）。

### 6-1. 単軍団「クイック選別」
- 上記フェーズ順に、各スロットで**スコア最大の未使用武将**を選択。

### 6-2. 複数軍団「全軍団編成」（全体最適：段階開放グローバル貪欲＋入れ替え改善）
- 軍団番号順の逐次配置は**しない**。各フェーズで **全対象軍団の対象スロット × 全候補武将**を評価し、
  **毎回いちばん貢献度の高い (武将×スロット) を全体から選ぶ**（グローバル貪欲）。
  - スコアは (ユーザー, 兵種, スロット種) で決まるため、同一comboは代表1つに集約して高速化。
- その後、**入れ替え改善（local search）**を最大3パス／時間予算2秒で実施:
  - 同ユーザー・**同フェーズ内**の2スロット間で武将を入れ替え、スコアが上がるなら採用（フェーズをまたがず統率確定を保つ）。
  - 配置武将を同ユーザーの未使用候補と置換し、上がるなら採用（主陣枠に戦車は入れない）。
- 共有capプールは配置のたびに更新し、限界貢献に反映。

### 6-3. 共通
- スコア0でも空きスロットは埋める（**候補内の**最低優先で配置）。
- 候補が足りずに埋まらないスロットは **空きのまま**にする（許容）。
- 同一ユーザー内で同じ武将が複数スロットに入ることはない（重複防止）。

### 6-4. 軍団内の並べ替え（選定後に枠を確定）
段階開放（§6-0）で「**統率5 / 主陣の武力・知性10 / 角陣3**」が選定済み。これを最終配置に落とす:

**統率枠（5）**
- 統率値の高い順に 部隊1→5（段階開放で選ばれた統率系5人がそのまま統率枠に残る）。

**武力枠・知力枠（主陣の10人を振り分け）**
1. **担当条件スキル優先**: 先鋒/前衛担当 → 武力枠（武力値順）、軍師/参謀担当 → 知力枠（知性値順）。
2. **残りは適材適所**: 武力値 ≧ 知性値 なら武力枠、そうでなければ知力枠（空きのある枠へ）。
3. 各枠内は能力値の高い順に 部隊1→5（武力枠＝武力値、知力枠＝知性値）。
   ※ 武力/知力の担当条件スキルは稀（多くは統帥＝統率担当）なので、実際はほぼ能力値で振り分けられる。

**角陣（3）**
- 段階開放の配置（戦車優先→兵種）をそのまま確定（並べ替えない）。

→ **18人が決まった時点で「統率5・角陣3」の配置が確定**し、武力/知力枠は担当条件＋能力値で振り分く。
　戦車は角陣のみに選定されるため部隊枠には現れない（§6-5）。単軍団・全軍団編成の両方に適用。

### 6-5. 戦車武将の制約
- **1軍団あたり戦車武将は最大3人**（角陣3枠に対応）。選定フェーズで4人目以降は候補から除外。
  - クイック選別・全軍団編成（貪欲＋入れ替え改善）の両方で上限を厳守。
- **戦車武将は角陣のみに配置**（部隊枠には置かない。6-4参照）。
- 判定: `troop_type === '戦車'`。

## 7. 派遣不要スキルの扱い（編成スコアとは別の集計ルール）

- 派遣不要スキルは配置されていなくても、**所持していれば数値は常時加算**される（属性マトリクス・上限プールに反映）
- **派遣不要スキルしか持たない武将は、自動編成では配置しない**（候補プールから除外）。
  - 判定: 派遣不要を除いた戦闘系スキルが1つも無い武将（`hasPlacementCombatSkill` が false）。
  - ただし**手動選択（ドロップダウン）では従来どおり選択可能**。
  - 数値自体は上記のとおり所持していれば常時加算されるため、配置しなくても集計に反映される。

## 8. 優先度の重み（参考）

第一優先を最重視し、2倍ずつ減衰:

| 優先 | 重み |
|---|---|
| 第一 | 16 |
| 第二 | 8 |
| 第三 | 4 |
| 第四 | 2 |
| 第五 | 1 |

各武将のスコア = Σ（各優先度にマッチしたスキルの上限適用後の値 × その優先度の重み）
