1. はじめに

1.1 このアプリでできること

三国覇王戦記の 4プレイヤー × 8軍団 編成を画面上で組み立てて、スキル効果の合計を可視化するツールです。所持武将を登録し、適切な兵種と配置を選ぶことで、集結戦に向けた最適な編成を検討できます。

  • 武将所持データの管理（突破段階・装備・将印）
  • 編成の構築（クイック自動編成サポート）
  • 属性マトリクスでスキル効果合計を一目で確認
  • 上限プール状況の表示（バフ重複時の余裕量）
  • 友人とのデータ共有（個別JSON or リアルタイム同期）

1.2 利用者の想定

  • 三国覇王戦記をプレイ中で、集結戦を意識した編成検討をしたい人
  • 仲間内で所持武将を共有・連携して編成を組みたい人
  • ゲーム内のスキル効果（とくに上限・共有プール）を整理して把握したい人

1.3 動作環境

環境対応
PC ブラウザChrome / Edge / Firefox / Safari の最新版
スマートフォンiOS Safari / Android Chrome 最新版
インターネット接続必須（初回読み込み時）。以降はオフラインでも動作可能
アカウント登録不要
データ保存場所ブラウザの localStorage（端末別に独立）

2. 起動・基本画面

2.1 アクセス方法

ブラウザで以下のURLを開くだけで利用開始できます。

https://yuichi4107-lab.github.io/sangoku-sim/

ブックマーク登録を推奨します。スマホの場合は「ホーム画面に追加」しておくとアプリのように起動可能です。

2.2 画面構成の全体像

画面は大きく3つのエリアで構成されます。

エリア機能
上部ヘッダープレイヤータブ／エクスポート・インポート／QRコード／使い方リンク
左：武将一覧所持武将の登録、フィルタ、一括操作
中央：編成エリア4プレイヤー×8軍団の配置、クイック選別ボタン
下部：集計結果属性マトリクス、上限プール、スキル詳細
フッター⚙️ グループ機能解錠ボタン（控えめ表示）

3. 武将所持データの登録

3.1 所持チェック

武将一覧の各行の左端にある所持チェックボックスをONにすると、その武将を所持済みと記録します。

3.2 育成段階の入力

項目選択肢説明
3突チェック突破3段階（4突との排他、両OFFで0）
4突チェック突破4段階
4装チェック装備完成済み
印0〜5将印枚数
ゲーム内では中間段階（1突/2突/装1〜3）もありますが、スキル発動値に影響するのはほぼ4段階のみのため、UI簡略化のため2値（0 or 4）にしています。

3.3 一括操作

武将一覧の上部に「一括（表示中の武将に適用）」のチェックボックスがあります。フィルタで対象を絞った状態で「所持」「3突」「4突」「4装」のいずれかをチェックすると、表示中の全武将に一括適用されます。

例: 「兵種=騎兵」「レア=橙」でフィルタ → 「所持」一括チェック → 騎兵橙全員が所持済みに。

3.4 フィルタ・検索

  • 兵種: 歩兵 / 騎兵 / 弓兵 / 戦車 / 万能
  • レア度: 橙 / 玄
  • 検索: 武将名 or 読み（部分一致）
  • 所持のみ: 所持済み武将だけ表示

4. 編成の組み方

4.1 プレイヤータブ

本アプリでは最大 4プレイヤー × 各2軍団 = 8軍団（集結戦の同じ陣）を構築できます。上部のプレイヤータブで対象プレイヤーを切り替えて、それぞれの所持状況・編成を編集します。

  • プレイヤーは追加・名前変更・削除可能
  • 所持データはプレイヤーごとに独立して保存
  • 編成は全プレイヤー共通で1セット表示

4.2 軍団の構成

各軍団は以下の構造になっています。

枠役割
主将（統率）軍団の率兵数を決定、統率系スキルが発動
副将×4枠武力/知性/副将枠など、効果を提供する補助武将
角陣陣形効果スキルが発動する独立枠

各枠で武将名を選ぶと、その武将のスキルが集計に反映されます。

4.3 優先属性の設定

編成上部「集結共通の優先属性」で 第一優先 / 第二優先 を選びます。これはクイック選別（自動編成）が候補武将を選ぶ際の優先順位として使われます。

選択肢は 12カテゴリ × up/down = 24択（詳細は付録10.1）。

4.4 自動編成（クイック選別）

各軍団に「クイック選別」ボタンがあり、押すと以下のロジックで自動配置します。

  1. 対象プレイヤーの所持武将から、軍団兵種に置ける候補を抽出
  2. 戦闘系スキルを持たない武将は除外
  3. 優先属性スキルを持つ武将を高く評価
  4. cap プールを考慮し、上限超過した場合は他属性の武将に切替
  5. 主将→副将の順に最適候補を選定

5. 集計結果の見方

5.1 属性マトリクス

編成下部に表示される表で、12のスキルカテゴリ × 4スコープの合計値を一覧できます。

列意味
集結集結戦（rally）スコープのスキル合計
軍団軍団内（legion）スコープ
角陣角陣（array）スコープ
自部隊自部隊（self）スコープ
  • セル内の値は 符号付き合計（例: +54%、-80%）
  • 緑＝アップ、赤＝ダウン、グレー＝ゼロ
  • セルをクリックすると詳細武将名・スキル名・上限値が展開
  • 全スコープでゼロの属性行は非表示

5.2 上限プール状況

各 cap_rule ごとの充足率を視覚化します。バフ重複時にどこまで余裕があるか・どの武将を入れれば埋められるかを示します。

表示要素意味
プログレスバー合計 / 上限 の充足率
余裕 N%上限まで残り何%か
上限到達上限ピッタリ or 溢れている
構成スキル既に入っている武将/スキルの内訳
候補武将編成外で同じ cap.rule を持つ武将提示

5.3 スキル詳細

武将ごとの解像度の高いブレイクダウン表示。各スキルの実効値・スコープ・cap情報・累加可否などを確認できます。

6. 友人配布用ツール（register.html）

6.1 友人へのお願い手順

所持武将データを多人数から集めたい場合、メインシミュレータとは別の 所持登録専用ツール を友人に使ってもらえます。

https://yuichi4107-lab.github.io/sangoku-sim/register.html

友人への案内テンプレート例:

お疲れさまです。三国覇王戦記の武将所持状況を集計したく、ご協力ください。

下記URLをスマホ/PCで開いて入力をお願いします。
👉 https://yuichi4107-lab.github.io/sangoku-sim/register.html

【手順】
1. 名前を入力
2. 所持している武将にチェック+段階入力（3突/4突/4装/印）
3. 「📤 JSONエクスポート」ボタンを押す
4. ダウンロードされたファイルを私に送ってください

入力途中で閉じても自動保存されるので、何度に分けてもOKです。

6.2 QRコードによる配布

メインシミュレータ上部の「📱 QR」ボタンを押すと、register.html のURLのQRコードが表示されます。画面共有や紙印刷、Discordへの貼付けなどに利用できます。

6.3 友人側の操作

  1. URLを開いて名前を入力
  2. 武将カードの所持チェック＋段階入力（スマホ最適化UI）
  3. 「📤 JSONエクスポート」をタップ → ファイルダウンロード
  4. そのファイルを LINE / メール等で依頼者に送信

入力途中の状態は端末ブラウザに自動保存されるため、中断・再開が自由です。

7. ユーザーデータの管理

7.1 ユーザーをエクスポート

メインシミュレータ上部の「ユーザーをエクスポート」をクリックすると、登録済みのプレイヤー一覧から複数選択してJSONダウンロードできます。

  • 初期状態で全プレイヤーが選択済み
  • 「全選択」「全解除」ボタンあり
  • ファイル名: sangoku_user_{名前}_{日付}.json

7.2 ユーザーをインポート

「ユーザーをインポート」ボタンで、友人からもらった JSON（または自身のバックアップ）を取り込めます。複数ファイル同時選択可能。

状況動作
新規プレイヤー名新しく追加
同名プレイヤーが既存上書き確認ダイアログ表示。OK=上書き、キャンセル=スキップ
不正な形式スキップしてエラー表示

8. グループ同期機能

8.1 解錠

グループ同期は隠し機能として実装されており、初回はアクセスコード入力で解錠が必要です。

  1. ページ下端の ⚙️ ボタン をクリック
  2. アクセスコードを入力（管理者から個別に伝達）
  3. 解錠完了。以降はそのブラウザで常時表示
解錠状態はブラウザの localStorage に保存されます。共有PC等でロックに戻したい場合は「ロックに戻す」ボタンを使用してください。

8.2 クラウドへの保存／取得

解錠後に表示される「🔓 グループ」パネルで以下を操作します。

ボタン動作
⬇️ クラウドから取得クラウド最新データでこの端末を上書き
⬆️ クラウドへ保存現在のローカル状態をクラウドに送信（他端末・他メンバーに伝播）
自動同期機能はありません。すべて手動操作です。

8.3 同期モードと試作モード

パネル上部のモード切替ボタンで、グループ同期中の状態を制御できます。

モード動作
🔗 同期モード通常運用。⬆️保存ボタンはそのまま実行
🧪 試作モード⬆️保存ボタンが赤色になり、押すと「本番に反映しますか？」と確認

モード切替自体はデータ操作を伴わない、ワンタッチで即切替できます。

8.4 運用パターン

場面推奨操作
1人で複数端末を使い分け編集後 ⬆️保存 → 別端末で ⬇️取得
通話しながら共同編集同期モードのまま、編集→ ⬆️保存 を順番に
共同編集中に自分だけ試したい🧪 試作モードに切替、自由に編集
試作内容を本番反映試作モードのまま⬆️保存 → 確認OK
試作内容を破棄🔗 同期モードに戻す → ⬇️取得で最新を復元
last-write-wins 方式: 同時刻に複数人が保存すると後勝ち。複数人での同時編集は時間帯を分けるか、宣言してから行うのが安全です。
